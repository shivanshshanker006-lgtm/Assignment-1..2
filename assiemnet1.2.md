Assignment 1.2 — Development Environment Setup
Objective

To set up a basic web development environment using Visual Studio Code, Node.js, Live Server, and Prettier.

Software and Tools
Visual Studio Code — code editor
Node.js LTS — JavaScript runtime
npm — Node.js package manager
Live Server — runs the HTML page in a local browser
Prettier — formats code consistently
Project Structure
text
web-development-practice/
├── index.html
├── style.css
└── script.js

Procedure
Install Visual Studio Code.
Install the LTS version of Node.js.
Install Live Server and Prettier from the VS Code Extensions Marketplace.
Create the web-development-practice folder.
Create index.html, style.css, and script.js.
Link the CSS and JavaScript files to the HTML document.
Open index.html using Live Server.
Open the VS Code terminal and run node -v and npm -v to verify the installations.
Expected Result

The browser displays a webpage titled "Welcome to Web Development!" with a styled button. Clicking the button displays a confirmation message, demonstrating that JavaScript is working.

The terminal displays version numbers for Node.js and npm.
